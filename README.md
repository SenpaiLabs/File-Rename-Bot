### Quick VPS Deployment

```bash
# 1. Clone the repository
git clone https://github.com/SenpaiLabs/File-Rename-Bot.git
cd File-Rename-Bot

# 2. Setup configuration
cp .env.example .env
nano .env  # Edit with your credentials

# 3. Run deployment script
python3 bot.py 
```
## Rᴇǫᴜɪʀᴇᴅ Cᴏɴғɪɢs

* `BOT_TOKEN`  - Get Bot Token From @BotFather
* `API_ID` - From my.telegram.org
* `API_HASH` - From my.telegram.org
* `ADMIN` - Bot Admin User ID. Multiple IDs use space to split
* `DB_URL`  - Mongo Database URL From https://cloud.mongodb.com
* `DB_NAME`  - Your Database Name From Mongodb (Default: Senpai_Rename_Bot)
* `FORCE_SUB` - Your Force Sub Channel Username Without @
* `LOG_CHANNEL` - Bot Logs Sending Channel ID (Optional)
* `SENPAI_PIC` - Welcome Image URL (Optional)
